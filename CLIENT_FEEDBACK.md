# Фидбек клиента (Ирина) — 2026-09-01

Статус: собрано, не реализовано. Ждём файл с текстовой разметкой от Ирины перед версткой блока «Четыре шага» (см. п.4).

## 1. Воздух, сетка, восприятие сайта

- Проблема: верстка "зажата" узким контейнером, большие пустые поля по бокам. H1 "Мост между вашим производством..." переносится на несколько строк.
- Решение:
  - Расширить `max-width` контейнера (сейчас похоже на Bootstrap ~1140-1200px) до 1440px или относительных величин (90vw).
  - H1 — в одну-две строки, без рваных переносов.
  - При растяжении контента следить за симметрией — см. п.2 (буква «М» справа как фоновая графика).

## 2. Фирменный стиль: буква «М»

- Проблема: массивная «М» на Hero перетягивает внимание, "непрезентабельно".
- Решение:
  - Hero: убрать/сильно сдвинуть влево, сделать едва заметной.
  - На остальных смысловых блоках — дублировать «М» справа как водяной знак.
  - Фоны блоков чередуются (белый / светло-серый) → буква должна менять оттенок.
  - Реализация: SVG с `fill: currentColor` + `opacity`, либо CSS-переменная на классе секции, например `.bg-gray .bg-letter-m { fill: #ffffff; }`.

## 3. Смена стратегии лидогенерации — "не надо мне звонить"

- Проблема: акцент на звонки противоречит процессам клиента (B2B, экспорт/импорт, асинхронная переписка).
- Решение:
  - Header: убрать номер телефона и "Звонить". Оставить один CTA — "Запросить консультацию".
  - Модалка по клику на CTA: приоритетный способ связи — Email.
  - Footer/блок контактов — пересобрать иерархию, строго в этом порядке:
    1. Email (самый крупный/заметный)
    2. WeChat (критично для Китая)
    3. Telegram
    4. WhatsApp
    5. Телефон — обычным текстом, без выделения, просто как формальность.

## 4. Контент vs визуализация

- Проблема: перегруз текстом, "картинки только на двух слайдах", высокий когнитивный груз.
- Решение:
  - Переверстать текстовые блоки (например "Четыре шага") под Z-паттерн: текст слева/картинка справа, следующий блок — зеркально.
  - **Блокер: ждём от Ирины текстовый файл** с точной разметкой — что сократить, что убрать, куда вставить фото. Не трогать верстку этих блоков до получения файла.

## 5. QA-баг: фиолетовые карточки

- Проблема: текст в карточке (например "До результата") вываливается за пределы div — фиксированная `height` при динамическом контенте.
- Решение: `min-height` / `height: auto` / flexbox (`flex-grow: 1`), либо адаптивный размер шрифта на мобилке/планшете.

## 6. Мультиязычность (i18n)

- Нужны минимум RU / EN / ZH (ZH логичен — есть WeChat в контактах).
- Переключатель языков — в Header, правый верхний угол.
- Референс: сайт Heavy Metallurgy.
- Архитектура: заложить i18n-библиотеку сейчас (стек проекта — Vite/vanilla, см. `vite.config.js`, `src/`). Все строки — в JSON-словари, чтобы потом просто подставить переводы от Ирины.
